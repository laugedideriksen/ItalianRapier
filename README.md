# Italian Rapier

This document is a compilation of texts on Italian rapier fencing.
Some were originally handouts, others documentation, yet others a way for me to work through a topic; most were written in preparation for classes taught at _Klingenspiel_ in Vienna, others are my own training notes.
All of them are living documents---each time I return to a topic, I update that chapter with new drills, ideas, and notes.
For now, the material here is confined to 'rapier alone', as that is my primary focus.
Once I start working on rapier and dagger, that will begin to appear here too.

The current version of this document can be found in the file `italianRapier.pdf`.
Anything that is not included in that file, is still work in progress.
